# My personal website

Hey, I'm Jhosel. This is my little corner of the internet, where I show what I've been building as a developer.

![Portfolio home](docs/screenshot.jpg)

## What's inside

- An ASCII version of me on the home page, generated from a photo.
- My work experience, from making games at UNAM to building internal apps at Grupo Salinas.
- My favorite projects. Some of them have a short demo video that plays when you hover over the screenshot, like waving at a 3D workspace or driving a taxi through Mexico City.
- Everything in Spanish and English.

## Built with

React, Vite, Tailwind CSS, Framer Motion and i18next.

## Running it

```bash
pnpm install
```

```bash
pnpm dev
```
